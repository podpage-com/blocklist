# Contributing

Issues and pull requests are welcome.

Keep the project's boundary narrow: Blocklist exchanges abuse observations; enforcement belongs to consumers.

For changes:
1. Explain the interoperability or security problem being solved.
2. Include tests for API behavior.
3. Preserve backwards compatibility where practical.
4. Do not commit real participant API keys, private IP lists, or production data.

Run `python manage.py test` before submitting a pull request.
